EMERGENCY PROCEDURES

  API DOWN (503 / Connection refused)
    1. Check: flyctl status
    2. View: flyctl logs -a orchestra-box-office | head -50
    3. Restart: flyctl machines restart
    4. If still down: Rollback → flyctl releases rollback

  DATABASE UNAVAILABLE (Connection timeout)
    1. Check: Database provider status page
    2. View: flyctl logs | grep database
    3. Notify users: "Cloud sync temporarily unavailable"
    4. Estimated fix time: [contact DevOps]

  HIGH ERROR RATE (>5%)
    1. Check: flyctl logs | grep -i error | head -20
    2. Identify: Common error pattern
    3. Deploy: Hotfix (v1.0.1) if critical
    4. Or: Rollback to v0.9.9 if needed

  ROLLBACK (If critical issue)
    Command: flyctl releases rollback
    Downtime: 2-5 minutes
    Data loss: None
    User impact: Cloud features disabled until v1.0.1 released
